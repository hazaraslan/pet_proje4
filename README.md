# E-Ticaret Console


## Proje Hakkında

Bu proje, Python ile geliştirilmiş basit bir konsol tabanlı e-ticaret uygulamasıdır. Kullanıcılar ürünleri görüntüleyebilir, sepete ekleyebilir, sipariş oluşturabilir ve satış raporlarını inceleyebilir.

## Özellikler

* Ürün listeleme
* Sepete ürün ekleme
* Sepeti görüntüleme
* Siparişi `orders.csv` dosyasına kaydetme
* Pandas ile satış analizi
* Matplotlib ile satış grafiklerini oluşturma

## Kullanılan Teknolojiler

* Python
* Pandas
* Matplotlib
* CSV Dosya İşlemleri
* Nesne Yönelimli Programlama (OOP)

## Kurulum

Gerekli kütüphaneleri yükleyin:

```bash
pip install pandas matplotlib
```

Ardından projeyi çalıştırın:

```bash
python main.py
```

## Proje Yapısı

* **Product** → Ürün bilgileri ve stok yönetimi
* **Cart** → Sepet işlemleri
* **Store** → Mağaza ve sipariş yönetimi
* **orders.csv** → Sipariş kayıtları

## Geliştirici

Bu proje, Python programlama ve veri analizi becerilerini geliştirmek amacıyla dönem sonu projesi olarak hazırlanmıştır.
